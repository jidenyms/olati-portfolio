# Oladami Design Portfolio

A responsive client website for **Oladami Design**, a Nigerian painter, interior designer, and architectural creative. The site presents the client's services, portfolio, professional story, testimonials, and contact options in a focused single-page experience.

## Live website

[View Oladami Design](https://oladamidesign.vercel.app)

## Features

- Responsive navigation with a mobile menu
- Hero section and professional biography
- Project gallery
- Services and testimonials sections
- Animated page elements
- Contact form integration with EmailJS
- Social and direct-contact links

## Built with

- HTML5
- CSS3
- JavaScript
- Font Awesome
- AOS animations
- EmailJS

## Run locally

No build step is required.

```bash
git clone https://github.com/jidenyms/olati-portfolio.git
cd olati-portfolio
```

Open `index.html` in your browser, or run it with a local development server such as VS Code Live Server.

## Project context

This was developed as a client project to create a professional online presence for an artist whose work spans painting, interiors, and architectural design.
